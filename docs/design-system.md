# سیستم طراحی فروشگاه

## روش و محدودیت ابزار

مهارت محلی design-system برای ساخت توکن سه‌لایهٔ پایه، معنایی و کامپوننت به‌کار رفت. دستورالعمل UI/UX Pro Max که در پیوند پروژه آمده بود در محیط نصب‌شده موجود نبود و اجرای CLI آن نیز به دسترسی npm نیاز داشت که فراهم نشد. در نتیجه، این سند تصمیم‌های پیاده‌شده را ثبت می‌کند و ادعای استفاده از آن مهارت ندارد.

جهت بصری: فروشگاه روشن، محصول‌محور و گرم با بنفش آلو، سبز کاجی، مرجانی و پس‌زمینهٔ شنی. گرادیان پررنگ و هویت برند نهایی اضافه نشده است؛ نام، لوگو و محتوای واقعی از مدیریت فروشگاه قابل تنظیم‌اند.

### قواعد معنایی و کنتراست

- دکمهٔ اصلی آلو با متن سفید؛ ثانویه کاجی با متن سفید؛ عمل مخرب با قرمز و برچسب متنی.
- تخفیف و هشدار از زعفرانی/مرجانی می‌آیند؛ موفقیت و شکست علاوه بر رنگ، متن وضعیت دارند.
- قیمت جاری تیره و قیمت قبلی کم‌رنگ/خط‌خورده است.
- متن معمولی از توکن متن اصلی یا ثانویه استفاده می‌کند؛ متن کم‌رنگ تنها برای راهنمای غیرحیاتی است.
- focus با outline آبی و فاصلهٔ قابل‌دیدن مشخص می‌شود. وضعیت غیرفعال فقط با تغییر رنگ منتقل نمی‌شود؛ کنترل واقعاً disabled است.
- نسبت کنتراست متن اصلی روی زمینه 15.32:1، متن ثانویه روی سفید 8.46:1، متن کم‌رنگ روی زمینه 5.50:1، placeholder روی سفید 5.82:1، دکمهٔ اصلی 12.08:1، دکمهٔ ثانویه 9.80:1، خطا روی زمینهٔ خطا 5.66:1، هشدار 5.83:1، اطلاع 6.24:1، focus روی سفید 5.09:1 و مرز ورودی روی سفید 3.79:1 است.
- این جفت‌ها حداقل WCAG AA متن عادی (4.5:1) و کنترل‌های مرئی (3:1) را می‌گذرانند. متن غیرفعال تیره‌تر شده تا در زمینهٔ غیرفعال 6.70:1 بماند.

توکن‌ها در static/css/tokens.css تعریف شده‌اند؛ مقدار خام رنگ را در قالب‌ها تکرار نکنید.

## تایپوگرافی و چیدمان

- پیکربندی ساخت فونت Vazirmatn خودمیزبان است؛ به‌دلیل نبود دسترسی به registry npm، فایل فونت در این محیط تولید نشد و فعلاً fallbackهای Tahoma و Arial استفاده می‌شوند. پیش از انتشار، npm run build را در محیط دارای دسترسی به registry اجرا کنید.
- متن بدنه ۱۶ پیکسل با line-height 1.85؛ متن کوچک ۱۴ پیکسل؛ سلسله‌مراتب عنوان با اندازه‌های ۲۲، ۲۸ و ۳۶ پیکسل.
- اعداد قیمت از ارقام فارسی با جداکنندهٔ سه‌رقمی استفاده می‌کنند؛ شناسه، SKU، تلفن و کد رهگیری با bdi یا جهت LTR ایزوله می‌شوند.
- مقیاس فاصله بر مبنای ۴ پیکسل است؛ radiusها ۸، ۱۲، ۱۶ و ۲۰ پیکسل؛ ظرف اصلی حداکثر ۸۰rem.
- نقاط تغییر: 1100px برای ستون‌ها، 800px برای ناوبری و داشبورد، 600px برای شبکهٔ موبایل.
- CSS از ویژگی‌های منطقی RTL مانند margin-inline و inset-inline استفاده می‌کند.

## اجزا و حالت‌ها

- دکمه‌ها: اصلی، ثانویه، outline، quiet و destructive؛ hover/active/focus/disabled مشخص.
- ورودی‌ها: زمینهٔ سفید، خط خنثی، focus آبی و خطای متنی.
- کارت محصول: تصویر با نسبت ثابت، قیمت، وضعیت موجودی و فاصلهٔ یکسان.
- جدول مدیر: سرستون متمایز، hover کم‌رنگ و پیمایش افقی در نمایشگر باریک.
- پیام‌ها و badgeها وضعیت را با متن و رنگ منتقل می‌کنند.
- بنر صفحهٔ اصلی میان چند بنر می‌چرخد، با تمرکز/hover متوقف می‌شود و حرکت خودکار برای prefers-reduced-motion خاموش است.
- کاهش حرکت، outline کیبورد، skip link، برچسب فرم و alt تصاویر در CSS/قالب‌ها پیش‌بینی شده‌اند.
